# Security

Do not include credentials, cookies, CSRF values, account captures or private
request/response content in issues or pull requests. Use GitHub's private
vulnerability reporting for this repository when available. If it is
unavailable, open a minimal issue requesting a private contact without exposing
the vulnerability or sensitive material.

Session bootstrap requires the host's explicit authorization. No credentials
or live account/operation catalog ship with this project. Tests and the runnable
example use synthetic data and mocked transports.
